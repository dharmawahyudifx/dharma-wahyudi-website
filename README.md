# Dharma Wahyudi — Website Personal Branding

Website personal branding profesional untuk Dharma Wahyudi, seorang content creator Indonesia yang membahas teknologi, kecerdasan buatan (AI), dan masa depan.

## Teknologi

- React + TypeScript
- Vite
- Tailwind CSS
- Lucide React (icons)

## Pengembangan Lokal

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Hasil build berada di folder `dist/`.

## Deploy ke Cloudflare Pages

1. Buat akun di [Cloudflare Pages](https://pages.cloudflare.com/)
2. Hubungkan repository GitHub ini
3. Atur konfigurasi build:
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
4. Deploy
